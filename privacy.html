gws CLI 개인정보처리방침

gws CLI는 PTJ Comics 팀이 자기 Google 계정의 Gmail, Drive, Calendar, Sheets, Docs 데이터를 사내 PC에서 관리하기 위해 쓰는 내부용 도구입니다.

  • Google 사용자 데이터는 로그인한 사용자 본인의 요청을 처리하는 데에만 사용합니다.
  • 인증 정보와 데이터는 해당 사용자의 PC에만 저장되며, 외부 서버로 전송하거나 제3자와 공유하지 않습니다.
  • 광고나 판매 목적으로 데이터를 사용하지 않습니다.
  • 사용자는 Google 계정 설정(myaccount.google.com/permissions)에서 언제든 접근 권한을 철회할 수 있습니다.

Google API 서비스에서 받은 정보의 사용은 Limited Use 요구사항을 포함한 Google API Services User Data Policy를 따릅니다.
